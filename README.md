# Ever Call Recorder — JoseloFarias fork

Proyecto Android de grabación de llamadas mantenido por **JoseloFarias**, orientado a evaluar y mejorar alternativas de captura confiable en Android moderno.

## Objetivos

- Priorizar estabilidad y calidad de grabación.
- Mantener el proyecto auditable y sin telemetría innecesaria.
- Validar compatibilidad por dispositivo/versión de Android antes de declarar soporte.
- Preservar atribuciones y licencia del proyecto base.

## Estado

En evaluación y mantenimiento dentro del conjunto de herramientas de grabación de llamadas.

## Desarrollo

```bash
git clone https://github.com/joselofarias-byte/Ever-Call-Recorder.git
cd Ever-Call-Recorder
./gradlew assembleDebug
```
